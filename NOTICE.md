# Происхождение материалов

- input/original.apk — фирменный PICO AppManager.
  Декомпиляция и ресурсы являются производными исследовательскими материалами;
  исходная лицензия и права PICO не заменяются лицензией этого комплекта.
- input/lsposed-original — модуль с оригинальным README,
  исходниками, credits и build files. Отдельный LICENSE в полученном дереве не обнаружен.
- vendor/shizuku — официальный Shizuku API 13.1.5, MIT; текст лицензии включён.
- src/, scripts/, tests/, docs/ — подготовленные в этой задаче расширения и материалы.

Комплект хранится локально. Не публиковался и не отправлялся третьим лицам.
Закрытые ключи подписи не включаются в репозиторий. Исторические локальные журналы, снимки и копии APK в validation/ относятся к прежним проверкам; снимки баз Store в build/store-inspection исключены из Git и не нужны для сборки.
Исходный APK может содержать публичные идентификаторы SDK и сетевые адреса производителя;
они не являются учётными данными пользователя.

- magisk/META-INF/com/google/android/update-binary — официальный установщик Magisk v28.1, GPL-3.0; источник и лицензия сохранены в magisk/.
