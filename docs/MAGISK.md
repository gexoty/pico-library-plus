# Magisk: системная версия Pico Library

Версия предназначена для совместимого Pico 4 с root и Magisk. Это не универсальный APK для любых Android-устройств. Package name — com.pvr.appmanager, launcher — прежний com.pvr.appmanager.AllAppActivity. Код и интерфейс общие со standalone-версией.

ZIP содержит module.prop, customize.sh, штатный установщик Magisk и его лицензию; приложение находится строго в system/priv-app/AppManager/AppManager.apk. В том же каталоге есть пустой .replace; customize.sh также указывает REPLACE для этого каталога. Используется штатный Magic Mount. Физический /system и оригинальный input/original.apk не меняются. service.sh, Zygisk, signature spoofing и собственных SELinux-правил нет.

Установщик зафиксирован из Magisk v28.1; источник и хеш указаны в magisk/UPSTREAM.md. Описание механизма: https://topjohnwu.github.io/Magisk/guides.html . Установку выполняет пользователь через приложение Magisk, затем перезагружает Pico 4. Автоматической установки в проекте нет.

Важное ограничение: собственная debug-подпись отличается от PICO. Наличие priv-app не передаёт платформенный сертификат, прежний shared UID или защищённые разрешения. sharedUserId намеренно отсутствует. Android и конкретная Pico OS могут отвергнуть замену из-за подписи, уже сохранённого пакета/данных, правил привилегированных разрешений или обновления из /data/app. Корректный ZIP не гарантирует совместимость. Проверки подписей и политики безопасности отключать не следует. Root выбирается существующим интерфейсом приложения; автоматического перехода между Root, System и Shizuku после отказа нет.

Для возврата отключить или удалить Pico Library в Magisk и перезагрузить устройство. Systemless-наложение исчезнет, исходный системный APK снова будет доступен. Отдельно установленное обновление /data/app и сохранённые данные могут влиять на результат; удаление пользовательских данных требует отдельного решения. При невозможности загрузки используйте заранее подготовленный способ отключения модуля средствами Magisk/восстановления конкретного устройства. Не удаляйте исходный AppManager и не записывайте системный раздел.

Установка этого модуля, обнаружение APK системой и запуск на Pico 4 в текущей задаче не проверялись. Документы FEATURE-UPDATE.md и DEVICE-STARTUP-FIX.md описывают предыдущие проверки standalone-сборки, а не этого модуля.
